== Sprint Plan

> **Goal:** Persist uploads and core transaction data.

.User Stories
****
[horizontal,labelwidth=30,itemwidth=70]
**Persistence**:: Upload PDF save for each parsed `{date,description,amount,payee}` row in `transactions`.
**Auth-Scope Persistence**:: Anonymous uploads are draft-only; authenticated saves persist.
****

.Backend Tasks
****
. Define `Transaction` model and `transactions` table; ensure `Base.metadata.create_all()` runs on startup.
. Update `/api/upload` to bulk-insert parsed rows into SQLite via SQLAlchemy.
. Write unit/integration tests for upload → DB and user-scoped transactions.
****

.Frontend Tasks
****
1. Ensure upload UI supports one-to-many statement uploads.
2. Ensure success/error messaging reflects draft vs authenticated save behavior.
3. Ensure transactions page supports authenticated persistence flows.
4. Write component/integration tests for upload and save behaviors.
****

== Acceptance Criteria
* Uploads persist in `transactions`.
* Anonymous uploads remain draft-only (no durable DB writes).
* Authenticated uploads and transaction saves are user-scoped and durable.
* Upload and transaction flows are validated by automated tests.
